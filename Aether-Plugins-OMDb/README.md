# OMDb

Fournisseur de métadonnées films/séries via [omdbapi.com](https://www.omdbapi.com).

- Clé API **requise** (champ secret `api_key`).
- Opérations : `search`, `details`, `images` (affiche).
- Hôtes réseau autorisés : `www.omdbapi.com` (API) et `m.media-amazon.com` (affiches).
- Les clés ne figurent jamais dans les messages d'erreur.
